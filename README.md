# Scrum Knowledge Quiz

A lightweight Python 3 and Tkinter multiple-choice quiz.

**Developer:** Hamdy Abou El Anein
**Contact:** info@daylightlinux.ch
**License:** GNU GPL v3 (see LICENSE).

## Features

- Modern desktop interface, replacing EasyGUI and Pygame.
- Four historical Scrum questions, including a multiple-selection question.
- Immediate scoring and replay, with automated tests.
- No external dependencies beyond Tkinter.

## Important

The original quiz uses historical Scrum terminology, including "Development Team".
It is intended for learning and nostalgia, not as an up-to-date certification exam.
Consult the official Scrum Guide for current terminology.

## Run

    python3 multiquestions-scrum-quiz.py

## Tests

    python3 -m unittest discover -s tests -v
